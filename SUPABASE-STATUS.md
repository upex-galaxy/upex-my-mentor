## 📊 Expected Database Schema

Based on the project documentation, the Supabase database should contain:

### Core Tables
- **`profiles`** - User profiles (students & mentors)
  - `id` (FK to auth.users)
  - `email`, `name`, `role`
  - `specialties[]`, `hourly_rate`
  - RLS: Public read, owner write

- **`reviews`** - User reviews and ratings
  - `id`, `reviewer_id`, `subject_id`
  - `rating`, `comment`
  - RLS: Public read, owner write

- **`conversations`** - Messaging conversations
  - `participant_1_id`, `participant_2_id`
  - RLS: Participants only

- **`messages`** - Individual messages
  - `conversation_id`, `sender_id`, `content`
  - `is_read` boolean
  - RLS: Conversation participants only

### Database Functions
- `get_all_unique_skills()` - Returns all mentor specialties
- `mark_messages_as_read()` - Marks messages as read
